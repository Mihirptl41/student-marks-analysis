# 📊 Student Marks Analysis using Python

## 📌 Project Overview
This project is a simple Python-based student marks analysis system. It analyzes student marks and displays important academic statistics.

## ✨ Features
- Display student names and marks
- Calculate average marks
- Identify the highest scorer
- Identify the lowest scorer

## 💻 Technologies Used
- Python 3
- Python Dictionaries
- Loops
- Built-in Functions

## 📂 Project Structure
```text
student-marks-analysis/
│
├── student_marks.py
├── README.md
└── .gitignore
```

## ▶️ How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python student_marks.py
```
